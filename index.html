Biografía breve

Quién soy

Soy estudiante de desarrollo web y me apasiona construir páginas accesibles, claras y bien estructuradas. Estoy dando mis primeros pasos con HTML y CSS, y aprendo algo nuevo cada día.

Habilidades

Uso de etiquetas con significado (header, nav, main, section, article, figure y footer) para que el documento se entienda sin mirar los estilos.

Cascada, especificidad, variables de color, CSS Grid con áreas nombradas, Flexbox y media queries con estrategia mobile-first.

Integración de Bootstrap por CDN sin perder la identidad visual del sitio, nociones de accesibilidad web y control de versiones con Git y GitHub.
